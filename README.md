# E-commerce QA Automation Portfolio

A compact QA project demonstrating practical software-testing skills for an e-commerce web application.

## Skills demonstrated
- Manual test-case design
- Selenium WebDriver with Java
- TestNG assertions and test structure
- Page Object Model concepts
- Positive and negative testing
- Defect reporting
- Regression and smoke-test planning

## Included
- `test-cases.md` – recruiter-friendly functional test scenarios
- `src/test/java/EcommerceSmokeTest.java` – short Selenium/TestNG example
- `defect-report.md` – sample defect report

## Typical scenarios
1. User login
2. Product search
3. Add product to basket
4. Basket validation
5. Checkout validation

This portfolio project is intentionally concise and focuses on readable, maintainable QA artefacts.
